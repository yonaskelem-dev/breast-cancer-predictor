Developed a multimodal breast cancer classification system using mammography and ultrasound images
Built deep learning models using ResNet-18/50 with PyTorch for binary classification (benign vs malignant)
Implemented weighted fusion strategy to combine both modality predictions for improved accuracy
Designed a Flask backend API for real-time prediction, history tracking, and report export
Created a responsive frontend dashboard using HTML, CSS, JavaScript, and Chart.js
Trained and evaluated models using Google Colab with GPU acceleration
Used BUSI, INbreast, and CBIS-DDSM datasets for model training and validation
Applied class imbalance handling and AUC-based fusion weight optimization
Achieved improved performance with multimodal fusion compared to single-modality models
Project deployed as a full-stack AI healthcare web application with downloadable report feature
(https://breast-cancer-predictor-lovat.vercel.app/)
